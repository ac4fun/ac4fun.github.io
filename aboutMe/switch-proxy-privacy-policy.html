SwitchProxy Privacy Policy

Welcome to SwitchProxy. We take your privacy seriously. This privacy policy will help you understand how we collect, use, and protect your information.

📊 Data Collection

SwitchProxy does NOT collect any user data.

All proxy configuration information (including proxy server addresses, ports, usernames, passwords, PAC configurations, etc.) is stored only in your local browser. We cannot access this data.

💾 Data Storage

SwitchProxy uses the chrome.storage.local API provided by Chrome browser to store your proxy configurations locally.

  • All data is saved only in your browser's local storage
  • Data is NOT uploaded to any external servers
  • Data is NOT shared with any third parties
  • You can delete this information at any time through your browser's data clearing feature

🔑 Permissions Explained

SwitchProxy requires the following permissions to function properly:

  • proxy - To configure and manage the browser's proxy settings
  • storage - To store your proxy configurations locally for future use
  • alarms - For automatic scheduled refresh of PAC scripts
  • webRequest - To automatically fill in username and password for proxies that require authentication
  • webRequestAuthProvider - To provide proxy authentication credentials
  • host_permissions (<all_urls>) - To fetch remote PAC script files (only used when you configure a PAC proxy)

These permissions are used solely to implement the extension's core features and for no other purpose.

🌐 Network Requests

SwitchProxy only makes network requests in the following scenario:

  • PAC Script Fetching - When you configure a PAC auto-proxy, the extension will download the PAC script file from the URL you specified
  • This is the only network request scenario, and it only accesses the PAC URL you configured yourself

🔒 Third-Party Services

SwitchProxy does NOT use any third-party analytics, tracking, or advertising services.

  • Does NOT integrate Google Analytics or other analytics tools
  • Does NOT use any advertising networks
  • Does NOT share data with any third parties

👤 User Data Protection

Your proxy configurations may contain sensitive information (such as proxy server addresses, authentication credentials, etc.). We take the following measures to protect this data:

  • All data is stored locally only, NOT uploaded to the cloud
  • Uses Chrome's secure storage API
  • Does NOT transmit your configuration data over the network

Recommendation: Do not use this extension on untrusted devices, and regularly change your proxy server authentication passwords.

🔄 Data Deletion

You can delete all data stored by SwitchProxy at any time:

  • Method 1: Manually delete all proxy configurations in the extension's options page
  • Method 2: Uninstall the SwitchProxy extension at chrome://extensions/
  • Method 3: Clear browser data (Chrome Settings → Privacy and Security → Clear Browsing Data → Extension Data)

📱 Cross-Device Sync

If you have enabled Chrome's sync feature, your proxy configurations may be synced to your other devices through your Google account. This is a Chrome browser feature and is not controlled by SwitchProxy.

  • Synced data is encrypted and stored by Google
  • SwitchProxy cannot access Google's sync servers
  • You can manage sync options in Chrome settings

🔐 Security

SwitchProxy follows Chrome Extension Manifest V3 security standards:

  • Uses Service Worker instead of persistent background pages
  • Minimizes permission requests
  • Code is open source and transparent for review

👶 Children's Privacy

SwitchProxy is not targeted at children under 13 years old, and we do not knowingly collect personal information from children.

📝 Privacy Policy Updates

We may update this privacy policy from time to time. The updated policy will be published on this page and users will be notified in the extension update notes.

  • Major changes will be prominently displayed in the extension
  • Continued use of the extension indicates your acceptance of the updated privacy policy

🌍 Applicable Laws

This privacy policy complies with the following regulatory requirements:

  • GDPR (General Data Protection Regulation)
  • CCPA (California Consumer Privacy Act)
  • Personal Information Protection Law of China
